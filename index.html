What is this?

The FIT (Flattened Image Tree) format bundles kernel, device tree, and ramdisk images for embedded Linux boot via U-Boot. It uses the Device Tree Blob (DTB) binary format internally.

FIT supports cryptographic signatures to ensure image integrity, but verification must be actively enforced at every level. Common weaknesses include:

  • Signatures disabled — CONFIG_FIT_SIGNATURE not enabled in U-Boot build
  • Configuration signatures not required — unsigned configurations can load unsigned images (CVE-2020-10648)
  • Unsigned images loaded without checks — individual image nodes lack signatures, only configuration is signed

This tool demonstrates two modifications:

  • Model property manipulation — the nested device tree's model property is changed, proving the DTB can be modified
  • Kernel replacement — the kernel image data is swapped entirely, showing unsigned payloads can be substituted

After modification, CRC32 and SHA-256 hashes are recalculated, but signature nodes are removed (we don't have the private key — that's the whole point).

Use responsibly and only on devices you own. This tool is for educational and authorized security research purposes only.
